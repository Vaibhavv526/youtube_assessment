# YouTube Learning Assistant

An AI-powered YouTube learning assistant that processes video transcripts, generates interview questions, and answers user queries using Retrieval-Augmented Generation (RAG).

## Features

- YouTube URL processing
- Automatic video ID extraction
- Multilingual transcript extraction
- Parallel transcript translation
- FAISS vector database
- OpenRouter-powered LLM
- Automatic interview question generation
- Context-aware question answering
- Streamlit user interface

## Tech Stack

- Python
- Streamlit
- LangChain
- OpenRouter
- FAISS
- YouTube Transcript API

## Setup

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies using pip install -r requirements.txt.
4. Configure your OpenRouter API key in .env.
5. Run streamlit run app.py.

## Security

Never commit API keys or environment files.
